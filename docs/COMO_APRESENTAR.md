# Demonstração da Pessoa 1

Fluxo sugerido para a apresentação:

1. Abrir a tela de Login.
2. Clicar em "Criar conta".
3. Mostrar o formulário de Cadastro.
4. Demonstrar rapidamente uma validação, por exemplo, deixar o e-mail vazio.
5. Preencher os dados.
6. Clicar em "Criar conta".
7. Após o backend estar integrado, mostrar o cadastro sendo enviado.
8. Voltar ao Login.
9. Informar e-mail e senha.
10. Clicar em "Entrar".
11. Mostrar o redirecionamento para o Feed.

O Feed deste pacote é apenas uma tela provisória para permitir o teste do fluxo. A Pessoa 3 deverá substituir essa tela pela implementação definitiva.
